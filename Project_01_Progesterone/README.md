# Project 01 – Progesterone Analysis with RDKit

## Objective

Analyze the molecular properties of Progesterone using RDKit.

## Molecular Properties

The project calculates:

- Molecular Weight
- LogP
- Topological Polar Surface Area (TPSA)
- Hydrogen Bond Donors
- Hydrogen Bond Acceptors

## Output

The project also generates a 2D image of the molecule.

## Tools

- Python
- RDKit
